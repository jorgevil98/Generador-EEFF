# Sitio público de EFicient — borrador local

Sitio estático preparado para GitHub Pages. Sin claves, datos de empresas ni OAuth implementado.

## Antes de publicar
- Confirmar responsable legal, correo, uso interno/externo y tratamiento real de datos.
- Completar y revisar privacy.html y terms.html; actualmente son borradores explícitos.
- Crear un repositorio dedicado para estos archivos públicos, sin publicar el proyecto privado EFicient.
- Habilitar GitHub Pages desde la raíz de la rama del repositorio dedicado y verificar HTTPS.

## Correspondencia con Intuit
- EULA: terms.html, solo después de completar el texto.
- Privacy: privacy.html, solo después de completar el texto.
- Host domain: dominio real publicado, por confirmar.
- Launch: launch.html; revisar que cumpla el flujo de acceso requerido.
- Connect/reconnect: connect.html es informativa. Sustituir por un flujo OAuth funcional antes de presentar como integración lista.
- Disconnect: disconnect.html es informativa; no revoca tokens ni certifica desconexión.
- Redirect URI OAuth: pendiente servicio seguro. No usar una página estática como sustituto del intercambio de códigos/tokens.

La página no completa el cuestionario Compliance ni garantiza credenciales de producción. Responder con la implementación real, probar sandbox y verificar los requisitos vigentes de Intuit.
